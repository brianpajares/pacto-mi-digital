# Operacion y Sostenibilidad

## Modelo operativo

| Funcion | Responsable sugerido |
| --- | --- |
| Product Owner | Coordinacion del proyecto |
| Editor principal | Comunicacion |
| Revisor tecnico | Especialista tematico |
| Academic Owner | Coordinacion academica |
| Community Manager | Coordinacion social |
| M&E Owner | Coordinacion / M&E |
| Tech Owner | Responsable tecnologico |
| Data Protection | Responsable de privacidad |

## Flujo editorial

1. Borrador
2. Revision tecnica
3. Revision comunicacion
4. Aprobado
5. Publicado
6. Archivado

Cada recurso debe registrar titulo, descripcion, fuente, version, fecha, responsable, licencia, region y estado.

## Publicacion de activos

Google Drive debe funcionar como repositorio de trabajo. La aplicacion no debe publicar cualquier archivo del Drive automaticamente. Solo los activos aprobados deben pasar al CMS/storage de produccion.

## M&E mensual

Revisar:

- Registros y asistencia.
- Modulos iniciados y completados.
- Resultados pre/post.
- Descargas de toolkit.
- Planes de accion.
- Replicas registradas.
- Evidencias pendientes.
- Satisfaccion.
- Actividad de comunidad.

## Checklist de lanzamiento

- Contenido inicial aprobado.
- Politicas legales y privacidad revisadas.
- Administradores entrenados.
- Backups configurados.
- MFA activo para staff.
- UAT con joven, lider, facilitador y administrador.
- Dashboard M&E validado.
