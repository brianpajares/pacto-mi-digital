# Toolkit técnico de formación PACTO-MI

*Prevención y respuesta frente a la minería ilegal en el Perú* — proyecto
Juventud en Acción contra la Minería Ilegal y el Crimen Organizado.
Fortalecimiento de capacidades en Cajamarca y Madre de Dios.

Estos PDF son la versión descargable de los módulos que la web publica completos
en `/aprende`. Se guardan en el repositorio y **no se despliegan en Vercel**: el
sitio los enlaza desde GitHub para mantener el despliegue liviano (presupuesto
de 5 MB, ver `scripts/check.mjs`).
